Ukládání kurzů

Kurzy se ukládají do souboru data/odds.json v repozitáři přes GitHub API. Potřebuješ fine-grained token omezený jen na tento repozitář s oprávněním Contents: Read and write (GitHub → Settings → Developer settings → Fine-grained tokens).

Token zůstane jen v tomto prohlížeči (localStorage). Nikam jinam se neposílá.
